# DevTools Hub

A collection of useful developer tools built with Next.js, React, and Tailwind CSS. The platform is designed to provide quick, accessible utilities for daily development, design, and data processing tasks.

## 📂 Project Structure

```text
├── app/
│   ├── globals.css      # Global styles and Tailwind CSS v4 imports
│   ├── layout.tsx       # Root layout
│   ├── page.tsx         # Home page listing all tools
│   └── tools/           # Individual tool pages with their own routes
│       ├── code-formatter/
│       ├── color-picker/
│       ├── crypto-toolkit/
│       ├── image-editor/
│       └── ...          # Other tool directories
├── hooks/               # Custom React hooks
├── lib/
│   └── tools.ts         # Centralized configuration and metadata for all tools
├── types/               # Shared TypeScript definitions
├── public/              # Static assets
└── next.config.ts       # Next.js configuration
```

## 🧰 Available Tools

### 💻 Development
- **URL Encoder / Decoder**: Encode or decode a URL or text string to a safe format for web transmission.
- **Code Formatter**: Format and beautify your code (Java, HTML, Vue, JavaScript, CSS, JSON, Text) with a side-by-side view and empty line removal.
- **Comment Remover**: Remove all comments and empty lines from your code (Java, Python, HTML, JS) and automatically format it.
- **Template Replacer**: Generate multiple text blocks by injecting data rows into a template. Great for generating SQL inserts from spreadsheet data.
- **Mermaid Editor**: Create diagrams and flowcharts using Mermaid syntax with real-time preview and export to PNG/JPG.
- **YAML Formatter**: Format YAML, remove empty lines, and sort keys alphabetically.
- **YAML Node Editor**: Visually parse YAML into an editable node tree with key/value editing, node addition/deletion, regex search & locate, and one-click export.
- **Crypto Toolkit**: Encrypt, decrypt, and hash data using MD5, Base64, AES, SM2, SM3, SM4, and more.

### 📝 Text
- **Text Split**: Split a URL or text string by a specific delimiter (e.g., `&`) and display parameters line by line.
- **Prompt Compare**: Compare multiple comma-separated prompts (e.g., Midjourney tags), extract common base tags, and show unique differences. Supports batch compare.
- **Text Diff**: Compare two texts side-by-side and see highlighted differences (added and removed words or lines).
- **Text Merger**: Merge multi-line text into a single line, and optionally break it into new lines based on specific symbols.
- **Text Line Breaker**: Format long texts by removing original line breaks and splitting into new paragraphs based on specified delimiters.
- **Markdown Editor**: A real-time Markdown editor with live preview, toolbar, and GitHub Flavored Markdown support.
- **Remove Duplicates**: Deduplicate text lines preserving first occurrence, with optional sorting and empty line removal.
- **Text Reader**: Paste multi-line text for line-by-line speech synthesis (with Smart Preload voice & browser SpeechSynthesis fallback), live center highlighting, speed/progress seeking, and typography controls.
- **URL Deduplicator**: Batch-extract, deduplicate, and subtract exclusion URLs from messy text via set difference (`A - B`), with one-click copy.

### 🎨 Design
- **UI Layer Composite**: Stack and arrange multiple UI image slices with distance positioning guides, opacity, and proportional scaling.
- **Color Picker**: Pick colors from a gradient and get RGB/HEX/HSL codes for CSS.
- **Image Color Picker**: Upload or paste an image and pick colors directly from it with zoom, pan, and color history support.

### 🖼️ Image Processing
- **PNG Metadata Extractor**: Extract text, prompts, and config details embedded in PNG files generated by AI tools.
- **Image Ratio Calculator**: Calculate proportional image sizes (scale up or down) with specific bounds or scale factor.
- **Picture Split**: Pixel-level precision image cropper letting you drag edges or set exact top/bottom/left/right pixel distances.
- **Image Editor**: Annotate images with arrows, text, freehand drawing, mosaic, and cropping functionalities.
- **Image Annotator**: Click to place auto-incrementing circular numbered markers on images with drag, double-click delete, multi-step undo, and customizable bottom caption export.
- **Picture Append**: Stitch and align multiple UI audit screenshots via clipboard paste (`Ctrl+V`), Excel-like grid cell placement, per-image resolution tuning, and solid/transparent background export.
- **Background Builder (背景图构建)**: Compose multiple vertical illustrations horizontally into wide desktop wallpapers (`16:9` 2K/4K, `16:10` 2560×1600, `21:9`, `32:9`, or custom) with Z-order overlap control, inter-image edge snapping, proportional canvas scaling, non-destructive cropping, and optional edge feathering.

### 📱 QR Code
- **QR Code Generator**: Generate customizable QR codes with colors, logos, and different error correction levels.
- **QR Code Scanner**: Decode QR codes by uploading an image, pasting from clipboard, or scanning directly with your camera.

## 🛠️ Getting Started

### Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) with your browser.

### Adding a New Tool

1. Create a new directory under `app/tools/` (e.g., `app/tools/my-new-tool`).
2. Create a `page.tsx` file in that directory with your tool's UI and logic.
3. Open `lib/tools.ts` and add a new entry to the `tools` array:
   ```typescript
   {
     id: 'my-new-tool',
     name: 'My New Tool',
     description: 'Description of what it does.',
     category: 'Utilities',
     icon: MyIconComponent,
     path: '/tools/my-new-tool',
   }
   ```

## 📦 Deployment

This project is configured for standalone output, making it easy to deploy to various platforms.

### Docker Container

A `Dockerfile` is included for containerized deployment.

```bash
# Build the image
docker build -t devtools-hub .

# Run the container
docker run -p 3000:3000 devtools-hub
```
